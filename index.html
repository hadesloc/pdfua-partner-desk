Does the software handle scanned ordinances and fillable PDF forms?
Yes. Scanned image PDFs receive an invisible searchable Unicode text layer (PDF rendering mode 3 Tr via offline RapidOCR ONNX) beneath the original scan so visual appearance stays pixel-identical while text becomes selectable and tagged. How does PDF Accessibility Studio handle cryptographically signed PDFs?
Modifying a PDF tag tree changes byte offsets and invalidates existing digital signatures (/Sig /ByteRange). The CLI and checker detect signature locks automatically so your team can run auto-tagging on the unsigned source PDF prior to applying final corporate e-signatures.
