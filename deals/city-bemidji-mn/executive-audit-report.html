Clause Technical Failure Screen Reader / ADA User Impact Affected PDFs

ISO 14289-1 §7.1Untagged Content, Missing Document Title, or Unmarked Artifacts
Content shall be marked as Artifact or tagged as real content
Blind users hear decorative headers/footers mixed into body text or cannot identify document title.4 / 5
ISO 14289-1 §7.3Figures & Graphics Missing Alternative Text (/Alt)
Figure tags shall include an alternative representation or replacement text that represents the contents marked with the Figure tag as noted in ISO 32000-1:2008, 14.7.2, Table 323
Screen readers skip informational charts, seals, and diagrams or announce 'unlabeled graphic' (WCAG 1.1.1).4 / 5
ISO 14289-1 §7.2Missing Natural Language (/Lang) or Broken List/Structure Hierarchy
Natural language for text in page content shall be determined
Text-to-speech engines use the wrong pronunciation rules or misread nested list items (LI/LBody).3 / 5
ISO 14289-1 §7.21.4.1Unembedded Fonts Used in Page Rendering
The font programs for all fonts used for rendering within a conforming file shall be embedded within that file, as defined in ISO 32000-1:2008, 9.9
Visual glyphs may fail to render consistently across low-vision magnification and reader platforms.2 / 5
ISO 14289-1 §7.21.4.2Incomplete Embedded Font CIDSet Stream
If the FontDescriptor dictionary of an embedded CID font contains a CIDSet stream, then it shall identify all CIDs which are present in the font program, regardless of whether a CID in the font is referenced or used by the PDF or not
Strict PDF/UA-1 and PAC 2026 validators reject the font descriptor due to mismatched glyph inventory.2 / 5
ISO 14289-1 §7.5Table Headers (TH) Missing Scope or Header-Cell Associations
If the table's structure is not determinable via Headers and IDs, then structure elements of type TH shall have a Scope attribute
Screen readers fail to announce column/row context when navigating financial or schedule tables (WCAG 1.3.1).2 / 5
ISO 14289-1 §6.2Missing MarkInfo / Tagged PDF Flag
The document catalog dictionary shall include a MarkInfo dictionary containing an entry, Marked, whose value shall be true
Screen readers treat the file as untagged and fall back to raw heuristic reading order.1 / 5
ISO 14289-1 §7.18.1Annotations Missing Accessible Descriptions (/Contents or /Alt)
An annotation (except Widget annotations or hidden annotations, or those having rectangle outside the crop-box) shall have either Contents key or an Alt entry in the enclosing structure element
Interactive page annotations are announced without meaningful labels to keyboard/screen-reader users.1 / 5
ISO 14289-1 §7.18.5Hyperlinks Missing Alternate Descriptions (/Contents)
Links shall contain an alternate description via their Contents key as described in ISO 32000-1:2008, 14.9.3
Screen readers read raw cryptic URLs instead of meaningful link purpose (WCAG 2.4.4).1 / 5
