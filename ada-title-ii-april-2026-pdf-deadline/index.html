FAQ

Frequently asked questions

Which PDFs must be remediated vs. archived under 28 CFR Part 35?
Active agendas, budgets, permits, fee schedules, enrollment packets, policies, and forms used to participate in or apply for public programs require WCAG 2.1 Level AA accessibility. Preexisting documents qualify for the narrow archive exception only if kept exclusively in a clearly labeled archive area, unmodified since the compliance date, and not used for active civic services.
Why remediate to ISO 14289-1 (PDF/UA-1) alongside WCAG 2.1 Level AA?
WCAG 2.1 Level AA defines functional accessibility (alt text, info & relationships, focus order, contrast, titles, language), while ISO 14289-1 (PDF/UA-1) defines exact PDF tag, table scope, font, and form widget bindings so NVDA, JAWS, and VoiceOver read the PDF reliably.
