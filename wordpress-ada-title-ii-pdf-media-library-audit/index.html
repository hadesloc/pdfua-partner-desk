Does the WordPress PDF scanner plugin send Media Library files to an external server?
No. Both the WordPress plugin (pdfua-ada-media-scanner.zip) and npx pdfua-ada-scanner inspect PDF byte streams locally on your own WordPress host or developer machine—zero external API calls.
How do we distinguish active Title II PDFs from archived WordPress uploads?
Under 28 CFR Part 35, preexisting PDFs qualify for the archive exception only if kept exclusively in a clearly designated archive section, unmodified since the April 2026/2027 deadline, and not used to apply for or participate in active public services.
